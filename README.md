# obsidian-vault-graph

为 Obsidian 库一键建立**关系图谱**的命令行工具。

一篇命令，把「一堆互不关联的笔记」变成「有枢纽、有标签、有内容关联的知识网络」——

- 🏷️ **内容标签**：中文分词（jieba TF-IDF）自动提取每篇笔记的关键词，连同主题/子目录层级一起写入 YAML frontmatter，图谱中出现标签聚类
- 🔗 **相关性双链**：基于 TF-IDF 余弦相似度，为内容相近的笔记自动互写「相关笔记」链接，跨主题也能连起来
- 🗺️ **MOC 枢纽笔记**：自动生成库总览（`🏠 知识库总览`）、每个主题文件夹的索引页（`_MOC 主题.md`）和标签索引（`🏷 标签索引`），图谱立刻有了骨架，孤岛消失
- 🎨 **图谱视图配色**：按主题为 Obsidian 图谱视图（Graph View）写入 17 组着色规则，一眼分清板块
- 🧹 **顺手修复**：指向已删除 PDF 的旧双链、文件名首尾空格等历史遗留问题
- 🛡️ **安全幂等**：动手前自动备份全部笔记；重复运行结果一致，不会重复注入

专为「从有道云笔记等工具导出、全是孤岛 md」的库设计，也适用于任何想快速建网的 Obsidian 库。

## 安装

```bash
pip install git+https://github.com/<user>/obsidian-vault-graph.git
```

需要 Python ≥ 3.9，唯一依赖是 [jieba](https://github.com/fxsjy/jieba)（中文分词）。

## 快速开始

```bash
# 先看看会发生什么（不写任何文件）
ovg build D:\path\to\your\vault --dry-run

# 一键建图
ovg build D:\path\to\your\vault

# 在 Obsidian 中重新打开该库，按 Ctrl+G 查看图谱
```

运行 `ovg build` 后，库里会多出：

```
🏠 知识库总览.md          # 库入口：主题板块 → 各主题枢纽
🏷 标签索引.md            # 全部标签与数量
<主题文件夹>/_MOC 主题.md  # 每个主题一篇枢纽笔记
各笔记.md                 # 头部多了 YAML tags，末尾可能多了「相关笔记」
```

## 命令

| 命令 | 作用 |
|------|------|
| `ovg build <库目录>` | 一键建图（备份 → 标签 → 相关双链 → MOC → 视图配置） |
| `ovg verify <库目录>` | 校验：frontmatter 覆盖率、失效链接、标签统计 |
| `ovg moc <库目录>` | 只重新生成 MOC 枢纽笔记 / 总览 / 标签索引 |
| `ovg fix <库目录>` | 修复指向 PDF 的旧双链、文件名首尾空格 |

`build` 常用参数：

| 参数 | 默认 | 说明 |
|------|------|------|
| `--dry-run` | 关 | 只演示将要做什么，不写任何文件 |
| `--no-backup` | 关 | 跳过自动备份（不推荐） |
| `--top-tags N` | 3 | 每篇笔记最多注入几个内容标签 |
| `--min-sim 0.28` | 0.28 | 相关性双链的相似度阈值，调高则链接更少更精 |
| `--max-related 3` | 3 | 每篇笔记最多几条相关笔记 |
| `--vocab-size 90` | 90 | 共享标签词表大小 |
| `--min-doc-freq 8` | 8 | 关键词进入词表的最低笔记数（防止标签碎片化） |
| `--skip-tags / --skip-related / --skip-moc / --skip-graph` | 关 | 分步跳过某个环节 |
| `--graph-force` | 关 | 覆盖已有的图谱颜色分组 |

## 工作原理

1. **扫描**：遍历库内 md（跳过 `.obsidian`、`.git`、`.trash` 等目录）
2. **备份**：全部 md 打包成 zip（默认放在库的上级目录，可 `--backup-dir` 指定）
3. **标签**：jieba 分词 → 全局词频统计 → 筛出出现在 ≥ `--min-doc-freq` 篇笔记中的关键词组成**共享词表** → 每篇笔记从词表选 ≤ `--top-tags` 个写入 frontmatter（共享词表让标签聚而不散，不会变成标签汤）
4. **相关性**：每篇笔记建 TF-IDF 向量，倒排索引加速余弦相似度计算；排除同主题、同目录，按归一化标题去掉「xxx(2)」「xxx(3)」式副本后取 top N
5. **MOC**：按目录结构生成分组索引，写入 `[[]]` 双链
6. **视图**：写 `.obsidian/graph.json` 颜色分组（旧配置自动备份为 `graph.json.bak_before_ovg`）
7. **校验**：统计 frontmatter 覆盖率与失效链接数（目标 0）

## 注意事项

- 运行前建议**暂停百度网盘 / OneDrive 等同步客户端**，避免文件占用导致写入重试
- 工具不会改动笔记正文，只在头部插入 frontmatter、末尾追加「相关笔记」区块；全部操作幂等，重复运行安全
- 从 PDF 转换来的笔记正文若含大量 `![](xxx.assets/xx.png)` 图片语法，工具会自动清洗后再分词，不会产生 `assets/png/http` 这类垃圾标签
- 图谱配色按顶层文件夹生成；以后新建文件夹想单独配色，在图谱面板「颜色分组」里加一条 `path:文件夹名` 即可

对某 1195 篇笔记的真实库执行 `ovg build`：

```
分词与关键词分析中（jieba TF-IDF）…
共享标签词表 90 个
计算内容相似度中…
已写回 1195 篇，双链 1221 条（覆盖 550 篇）
已生成 16 个主题枢纽笔记 + 总览 + 标签索引（共 175 个标签）
已写入 D:\...\obsidian\.obsidian\graph.json（17 个着色分组）
```

校验：1213 个 md 全部带 frontmatter，2451 条链接 0 失效，178 个标签。
